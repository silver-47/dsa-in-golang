# Go Data Structures & Algorithms

[![Go Version](https://img.shields.io/badge/Go-1.18+-00ADD8?style=flat&logo=go)](https://go.dev/)
[![Roadmap](https://img.shields.io/badge/Roadmap.sh-DSA-blue)](https://roadmap.sh/datastructures-and-algorithms)

An interactive, pure-code implementation of Data Structures and Algorithms in Golang, designed to strictly follow the [Developer Roadmaps: Data Structures and Algorithms](https://roadmap.sh/datastructures-and-algorithms) learning path.

## 🏗 Project Structure

The codebase is split into main areas that hold standalone executable scripts:

- **`ds/` (Data Structures):** Foundational data structures (like arrays, linked lists, trees). Each is implemented as an interactive terminal program.
- **`algo/` (Algorithms):** Core algorithms categorized by paradigm (Sorting, Searching, Dynamic Programming, etc.), designed to be run and observed.

## 🚀 Getting Started

### Prerequisites

- [Go 1.18 or higher](https://go.dev/dl/)

### Installation

Clone the repository:

```bash
git clone https://github.com/silver-47/dsa-in-golang.git
cd dsa-in-golang
```

### Running the Code

Since the project is structured as interactive CLI scripts, you can run the code directly.

For example, to play with the Array implementation:

```bash
go run ds/array/array.go
```

Then, simply follow the on-screen prompts to interact with the array data structure!
